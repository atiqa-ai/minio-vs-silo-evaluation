## config
  .gitleaks.toml extends the upstream default ruleset and adds three rules
  targeting this project's credential patterns:
    id = "lab-access-key-assignment"
    id = "lab-secret-key-assignment"
    id = "env-file-committed"

  Note: rules use character classes, not lookahead. gitleaks uses RE2,
  which does not support (?! ; placeholders such as <SECRET_KEY> and
  ${VAR} cannot match because '<', '>', '$' and '{' are excluded from
  the value classes.
