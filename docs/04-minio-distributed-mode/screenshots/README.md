# Screenshots — ST05

Screenshots are **supporting evidence only**. A screenshot alone is never
sufficient evidence for a PASS/FAIL claim (evidence guide, section 1).

Before any screenshot is committed, it must be checked for (evidence guide
section 13, guardrails 20):

* access keys, secret keys, passwords, tokens, private keys
* internal IPs, hostnames, domains, email addresses
* unredacted IAM or bucket metadata

Any image placed here must be listed in this subtask README's results table with
the reason it was needed. This directory is tracked with a placeholder so the
structure required by SRD section 10 exists in the repository even when no
screenshot is warranted.
